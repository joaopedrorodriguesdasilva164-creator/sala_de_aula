# sala de aula 

este projeto é um recurso educacional para que os alunos aprenda sobre programação de sistemas através da elaboração de um * software*.

o projeto é um sistema de gestão de sala de aula, em que será possível:

1. adicionar alunos;
2. remover alunos;
3. atribuir nota a alunos;
4. conferir situação do aluno;
5. imprmir relatório de alunos, com notas;
